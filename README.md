# Лабораторна робота №5–6 — JavaScript Fetch, JSON та OpenWeatherMap

## Файли
- `index.html` — завдання 1: завантаження JSON зі списками мов програмування і студентів.
- `1.txt` — список мов програмування у форматі JSON.
- `2.txt` — список студентів у форматі JSON.
- `weather.html` — завдання 2: отримання поточної погоди з OpenWeatherMap.

## Локальний запуск
Через VS Code відкрийте папку і запустіть Live Server для `index.html`.
Або відкрийте термінал у папці, запустіть `python -m http.server 8000` і відкрийте `http://localhost:8000`.
Не відкривайте `index.html` через `file://`, оскільки `fetch` локальних файлів може блокуватися браузером.

## Для погоди
1. Зареєструйтеся на https://openweathermap.org/ і отримайте API-ключ.
2. На сторінці `weather.html` введіть місто та ключ (наприклад, London), натисніть «Дізнатися погоду».
3. Код запитує поточну погоду через OpenWeatherMap: `GET /data/2.5/weather`.

**Увага:** не зберігайте свій API-ключ у файлах, які завантажуєте до публічного репозиторію. Введений ключ не записується у файли та не зберігається на сайті, але під час запиту він видимий у мережевих інструментах браузера. Для реального публічного продукту потрібен серверний посередник.
